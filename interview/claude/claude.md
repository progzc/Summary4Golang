# 1.复习面试问题
本项目主要是用来复习总结面试问题，需要把每次ai的问题和回答记录到md文档中，方面后面温习。

# 2.要求
- 按照问题进行分类，不同的问题放置在不同的md文档中，具体要求：
  - 网络类的问题放在network-qa.md
  - mysql类的问题放在mysql-qa.md
  - redis类的问题放在redis-qa.md
  - 消息队列类的问题放在mq-qa.md
  - go语言相关的问题放在go-qa.md
  - 系统设计问题放在design-qa.md
- md文档支持目录和跳转，每个问题要进行标号（标号形式一、二、...十一、等），标号每个分类下依次递增。若有相同的问题，需要在原问题标号下做增量更新删减
- 注意保持输出格式可读性（特别是表格不能错位）。
- 支持增量追加。
